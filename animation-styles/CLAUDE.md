# Video deliverables (user preference)

Every finished video ships with:
1. The video itself (`*.mp4`).
2. `cover.jpg`: a 1080x1920 cover picture.
   - Snapshot a strong frame with the caption overlay hidden.
   - Make it with `tools/make_cover.py frame.png cover.jpg "TOP" "BIG|TITLE" "sub" [#accent]`.
3. `POSTING.md`, with ready-to-paste posting text:
   - TikTok: caption with hashtags, plus a hook line.
   - YouTube Shorts: title, description, tags and a pinned comment.

Send all three to the user. Narration must start directly with the script, with no TTS preamble; check this by transcribing it.
